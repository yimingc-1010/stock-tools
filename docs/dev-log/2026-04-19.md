## Session 1

### Goal

Establish the initial repository scaffold for a Taiwan stock research toolkit and lock in
the "development log first" workflow.

### Scope

- Create the first project structure under `src/stock_tools/`
- Add architecture documentation and basic package configuration
- Add the first config, calendar, provider, storage, and research/backtest placeholders
- Add a minimal test suite that can run without network access

### Decisions

- Use four top-level modules for MVP: `core`, `data`, `research`, and `backtest`
- Keep runtime data structures DataFrame-first; reserve Pydantic models for boundaries
- Store raw prices separately from adjustment factors
- Treat point-in-time data handling as a first-class design constraint
- Delay `api/` until the data workflow is stable

### Risks

- The initial trading calendar is intentionally incomplete and needs official TWSE holiday
  integration in a later pass
- The FinMind provider is a thin adapter and has not been verified against live credentials yet

### Next Steps

- Wire a real data pull for one symbol and write/read it through the Parquet store
- Add small, fixed fixtures for price and adjustment-factor datasets
- Expand the calendar with official closures and exchange-specific overrides
